# Sistema de Gestión de Reservas

Sistema web para gestionar clientes, servicios y reservas de un centro de estética.

## Alcance v1.0
- Clientes: registrar, modificar y consultar.
- Servicios: registrar con precio y duración, y consultar.
- Reservas: registrar, consultar y cancelar.

## Estructura del proyecto
- `index.html` — página de inicio
- `css/styles.css` — estilos
- `js/app.js` — lógica del lado del cliente
- `db/schema.sql` — bd del sistema

## Cómo ejecutar
1. Clonar el repositorio: `git clone https://github.com/JoseChampiLima/proyecto-reservas-equipo6.git`
2. Abrir `index.html` en el navegador.

No requiere instalación ni servidor.
